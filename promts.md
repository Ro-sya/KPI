1. яка структура в Use Case Diagram та як її правильно написати
2. напиши мені use case diagram через mermaid за такою схемою: 
flowchart LR
    %% Актори
    User((Користувач))
    Admin((Адміністратор))

    %% Межа системи та прецеденти
    subgraph Система ["Система інтернет-магазину"]
        UC1([Переглянути catalogue])
        UC2([Оформити замовлення])
        UC3([Оплатити карткою])
        UC4([Застосувати промокод])
        UC5([Керувати каталогом])
    end

    %% Зв'язки
    User --> UC1
    User --> UC2
    
    UC2 -. "<<include>>" .-> UC3
    UC4 -. "<<extend>>" .-> UC2
    
    Admin --> UC5

мої актори це - внутрішні (гість, покупець, адміністратор), зовнішні (платіжна система, служба доставки). Також є такі use case: US-1: Оформлення замовлення; US-2: Скасування замовлення; US-3: Збереження товарів у Список бажань; US-4: Реєстрація та авторизація; US-5: Написання та відображення відгуків; US-6: Видалення акаунта
