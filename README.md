# Онлайн-магазин канцелярських товарів

## Про проєкт

Вебплатформа для швидкого та зручного замовлення канцелярії для навчання, офісу та творчості (зошити, ручки, органайзери, папір, степлер, ножиці, художнє приладдя).

## Основний функціонал та логіка

1. **Каталог та пошук**
      - Перегляд товарів за категоріями та брендами.
      - Фільтрація (за ціною, типом, кольором) та стрічка для пошуку.
      - Картка товару: наявність, характеристики, фото та оцінки/відгуки.

2. **Оформлення замовлення**
      - Додавання товарів до кошика з можливістю коригування кількості.
      - Вибір способу доставки (Нова Пошта, Укрпошта, кур'єр, самовивіз, поштомат).
      - Оплата: карткою на сайті або післяплата при отриманні.

3. **Особистий кабінет покупця**
      - Реєстрація та авторизація (email/пароль).
      - Історія замовлень із відстеженням їхнього статусу (_В обробці_, _Відправлено_, _Виконано_).
      - Збережені адреси доставки та списки обраних товарів ("Обране").

4. **Відгуки та рейтинги**
      - Можливість залишити оцінку (1–5 зірок) та текстовий відгук на придбаний товар.

5. **Панель адміністратора**
      - Управління каталогом (додавання, редагування, видалення товарів та категорій).
      - Обробка та зміна статусів замовлень користувачів.
